4 · Tracking every click and engagement per template

One template ID goes to many customers. Each send gets its own message ID, so every reply is traced back to the lead, template, flow and step.

Flow funnel · NWH_QUALIFIER

When do we get the message ID?

1 · On send Gupshup's send API returns messageId straight away (HTTP 202). Unlike the template ID it is unique to this customer and this send. We save messageId → lead, dealer, template, flow, step right then.
2 · First status callback The enqueued event brings WhatsApp's own ID (wamid…). We save it on the same row.
3 · On every tap The reply carries context.gsId (our messageId) and context.id (wamid) of the message it answers, plus our postbackText. One lookup gives lead, template, flow and step.
Engagement % per template = replies ÷ delivered, grouping sends by template_id. The date and time questions are session messages in the same flow, linked back to the template that started it.
